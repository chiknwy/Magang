Ringkasan Kegiatan Magang

01
Terminasi Kabel dan Crimping

Melakukan terminasi kabel UTP ke socket data dan patch panel, diuji dengan LAN tester mode fault check untuk memastikan tidak ada kabel putus, short, atau salah pasangan.

TerminasiSocketLAN Tester
02
Pembuatan Patchcord — PUSHIDROSAL

Membuat patchcord khusus proyek PUSHIDROSAL: pemotongan kabel UTP, penyusunan standar T568B, crimping konektor RJ-45, dan pengujian LAN tester.

PatchcordCrimping RJ45PUSHIDROSAL
03
Port Mapping dan Penyesuaian Titik Data

Port mapping antara switch, patch panel, dan outlet di lapangan. Setiap port dicocokkan dengan outlet fisik, didokumentasikan untuk kemudahan troubleshooting.

Port MappingLAN Tester
04
Survey Kebutuhan Kabel & WMR — PT Indoporlen

Survey lapangan: pengecekan tata letak, penentuan jalur kabel, estimasi panjang kabel, dan penentuan posisi Wireless Mobile Router untuk cakupan sinyal merata.

Site SurveyKabelWMR
05
Pemasangan Access Point dan Pengujian Koneksi

Pemasangan access point terhubung ke jaringan, pengecekan SSID, kekuatan sinyal, dan verifikasi koneksi internet stabil.

Access PointWireless
06
Splicing Fiber Optic dan Penataan Data Center

Splicing fiber optic dari kabel utama ke pigtail di data center: persiapan kabel, fusi dengan mesin splicer, penempatan ke tray, dan pengaturan kabel di rack 42U.

Fiber OpticData CenterSplicing

Tentang Program Magang

Program Overview

Program magang ini berfokus pada dukungan dan pemeliharaan jaringan mulai dari instalasi fisik di lapangan sampai dokumentasi teknis. Kegiatan meliputi terminasi kabel, port mapping, pemasangan access point, splicing fiber optic, serta penyiapan dokumentasi perusahaan.
